# Muse Protocol — Node.js

Independent Node.js research scaffold for authorized API integrations. No upstream Python code is redistributed. Uses an explicitly configured HTTPS API endpoint, not undocumented production endpoints.

## Usage

Requires Node.js 24. Run `npm test` for offline tests. Import `ApiClient` from `src/client.js` and configure an authorized API base URL and your own access token.

This project does not automate account creation, OTP collection, proxy rotation, regional restriction bypass, or promotional redemption. No live Muse API compatibility is claimed.

Reference for research context: https://github.com/duwqijlk/muse-protocol (upstream redistribution is restricted).
